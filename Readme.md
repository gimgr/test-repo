# Repo Purpose
This repo exists for the sole purpose of demonstrating that I do indeed possess the knowledge and skill to perform basic functions with git to participate in collaborative activities on GitHub.

# Repo Creation
I made this repo via the commandline tools git and gh (for remotely creating the repo to avoid the annoying step of dealing with the GitHub webpage) as well as VSCode for file creation and manipulation. I chose not to use GitHub Desktop as everything I wished to do was possible with the above tools.
